# Публикация статей

Для управления статьями задайте отдельный случайный `PUBLIC_ARTICLE_API_TOKEN` в окружении web. Не храните его в репозитории и не выводите в журнал. При отсутствии токена API отключён. Используйте HTTPS.

`PUT /api/internal/articles/<slug>/` с заголовком `Authorization: Bearer <token>` и JSON: `title`, `description`, `body` и `published_at`. Текст `body` является обычным текстом, HTML экранируется. `published_at` — ISO 8601 с часовым поясом, например `2026-11-10T12:00:00+03:00`. `null` сохраняет черновик. Будущая дата планирует публикацию. Повторный PUT обновляет статью, сохраняя дату создания; `updated_at` устанавливается автоматически. `GET` по тому же адресу возвращает содержимое и временные метки. Встроенные slug инструкций зарезервированы.

Публикуйте только проверенные инструкции и используйте понятные slug. Публичная статья доступна по `/guide/<slug>/` и включается в sitemap после наступления даты публикации. Текущий API принимает только текст; изображения и скриншоты пока не поддерживаются.
