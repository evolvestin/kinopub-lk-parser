# Публикация статей KinoPub Observer

Статьи можно создавать и обновлять через API без изменения шаблонов. Для авторизации используется уже настроенный `PUBLIC_ARTICLE_API_TOKEN`; не создавайте другой ключ в рамках публикации. Не печатайте его в логи, коммиты или URL. Все внешние запросы выполняйте по HTTPS.

## 1. Загрузить скриншот

`POST /api/internal/articles/assets/<slug>/`, `Authorization: Bearer <token>`, multipart field `image`. Лимит — 12 МБ; допустимы PNG, JPEG и WebP. API проверяет сигнатуру формата и возвращает публичный путь, например `/articles/assets/my-guide/<hash>.jpg`. Токен в ссылку не включается. Файл хранится в `/data/public-articles` и отдаётся с долгим immutable-кэшем.

## 2. Создать или обновить статью

`PUT /api/internal/articles/<slug>/`, тот же Bearer header и JSON:

```json
{
  "title": "Как найти фильм или сериал в Telegram-боте",
  "description": "Ищите по названию, сравните год и откройте подходящую карточку.",
  "published_at": "2026-11-10T12:00:00+03:00",
  "content_blocks": [
    {"type":"lead","text":"Короткий прямой ответ на вопрос читателя."},
    {"type":"image","src":"/articles/assets/my-guide/abc123.jpg","alt":"Экран поиска в приложении","caption":"Введите название в поле поиска."},
    {"type":"heading","text":"Как найти нужный тайтл"},
    {"type":"step","title":"Откройте поиск","text":"В нижней панели приложения выберите «Поиск».","result":"Откроется поле для поиска тайтла.","image":{"src":"/articles/assets/my-guide/step-01.jpg","alt":"В приложении выбран раздел поиска","caption":"Шаг 1. Откройте поиск в нижней панели."}},
    {"type":"step","title":"Введите название","text":"Введите название фильма или сериала в поле поиска.","image":{"src":"/articles/assets/my-guide/step-02.jpg","alt":"В поиске введено название фильма","caption":"Шаг 2. Введите название и дождитесь результатов."}},
    {"type":"paragraph","text":"Дополнение или ограничение."},
    {"type":"callout","text":"Полезная проверка перед следующим шагом."},
    {"type":"list","items":["Вариант проверки 1","Вариант проверки 2"]},
    {"type":"quote","text":"Короткое практическое правило."}
  ]
}
```

Разрешены блоки `lead`, `paragraph`, `heading`, `image`, `step`, `steps`, `list`, `callout`, `quote`. Для инструкций используйте `step`: действие, ожидаемый результат и скриншот находятся вместе в одном блоке; каждый снимок должен показывать именно этот этап. Не повторяйте один и тот же снимок в разных шагах/статьях. Обычный `image` используйте только для самостоятельной иллюстрации, а не вместо пошагового доказательства. HTML не нужен и не интерпретируется. Текст экранируется шаблоном. Каждое изображение должно ссылаться на ранее загруженный путь `/articles/assets/...`. JSON ограничен 2 МБ и 100 блоками.

`published_at: null` сохраняет черновик; дата с часовым поясом в будущем планирует публикацию. Дата в прошлом публикует страницу немедленно. Повторный PUT обновляет статью с тем же slug; `updated_at` меняется автоматически. `GET` возвращает тело, блоки и временные метки.

Опубликованные статьи доступны по `/guide/<slug>/`, показываются в списке и попадают в sitemap после наступления даты. Страница использует canonical URL, видимые даты, Article JSON-LD и постоянную ссылку на бота. Не добавляйте API token в статью, изображения, URL или structured data.

Полный процесс создания GEO-инструкций описан в [.agents/skills/kinopub-editorial/SKILL.md](../.agents/skills/kinopub-editorial/SKILL.md).
