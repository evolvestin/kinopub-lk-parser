# Настройки публичного сайта

Оферта размещена по адресу `/offer/`, политика конфиденциальности — `/privacy/`. Ссылки есть в навигации сайта, а политика также доступна из стартового сообщения и по команде `/privacy` бота. Адрес для Telegram формируется из `WEBAPP_PUBLIC_URL`.

`PUBLIC_OFFER_URL` необязателен: если он задан, ссылка «Оферта» ведёт на указанный адрес вместо `/offer/`. При изменении настроек окружения пересоздайте соответствующий сервис.

`PUBLIC_SITE_URL` задаёт основной публичный адрес сайта для перенаправления индексируемых страниц, открытых через публичный IP. Если он не задан, используется `WEBAPP_PUBLIC_URL`. Маршруты API, администрирования, метрик и локальные адреса не перенаправляются.
